# Margin

**Space for a second thought.**

Margin is an independent Outline companion for reading, connecting ideas, and keeping a reference close. The name comes from the space around a page: room to annotate, pause, and think. Use **Margin** in product copy and the home-screen label; use **Margin for Outline** when context is needed. Never imply that this is an official Outline client. Name availability and trademark clearance have not been assessed.

## Mark and app icon

![Margin app icon](Margin/Assets.xcassets/AppIcon.appiconset/AppIcon.png)

Two upright pages separated by a generous margin: sage on the left, warm paper on the right, with a single green margin rule. The paired pages express reference reading without tying the product to a device shape. The mark has no lettering, gradients, shadows, or tiny document lines.

The canonical 1024 × 1024 opaque icon is generated by `swift scripts/make-icon.swift`. Its square ink-green field lets iOS apply its own corner mask. Keep the page geometry and colors intact; never stretch, rotate, outline, or place text over the mark. For standalone use, leave clear space of at least one central gutter (56 units at master size). Below 32 points, use the simple paired-page silhouette without adding detail.

| Sage | `#A7CDBB` | Companion page and actions on dark surfaces |
| Paper | `#FAF8F2` | Warm reading background |

| Sepia | `#EFE2C6` | Sepia reading background |
| Umber | `#493B2C` | Sepia text |
| Night | `#172321` | Night reading background |
| Moon | `#E5EAE2` | Night text |

Use color sparingly around content. Keep system semantic colors for destructive actions, errors, and navigation chrome. Never use sage as small text on paper. Links are underlined as well as colored. Status must have a label or symbol, not color alone.

## Typography and layout

Use the system serif for welcoming headlines and document titles; use the system sans serif for navigation, controls, and reading text. Use the system monospace for code. No bundled fonts are required. Keep copy in sentence case, with short uppercase labels only for collection eyebrows.

Default reading text is 18 pt, adjustable from 14 to 30 pt in two-point steps, then scaled by Dynamic Type. Maintain a generous reading measure (760 pt maximum including padding), 28 pt page padding, and at least 44 pt touch targets. Avoid fixed-height text containers. Let content reflow at accessibility sizes.

## Reading appearance

Place **Appearance** in Settings immediately after the workspace profile. The `Aa` symbol labels this section; it is not a reader toolbar action.

- **System:** native background and text, following device light/dark appearance.
- **Paper:** Paper background, Ink text, Evergreen links.
- **Sepia:** Sepia background, Umber text, Evergreen links.
- **Night:** Night background, Moon text, Sage links.

“Color theme” selects coordinated app-wide backgrounds, surfaces, text, and accents. “Text size” adjusts the reading body. A live preview shows both choices. Store preferences on device and apply them to both the primary and reference reader, including saved documents. The selected theme also styles navigation, the collection browser, Settings, connection screens, and editors. System-owned dialogs and external sign-in web content retain platform or website styling. Markdown code and table surfaces retain adaptive MarkdownUI styling.

## Voice

Calm, direct, useful. Describe the action: “Keep beside,” “Open workspace,” “Sync page offline.” Prefer “Your reading shelf” to “Content repository.” Empty states should say what to do next. Avoid productivity claims, exclamation marks, and device-specific branding.

## Implementation

`Margin/Appearance.swift` owns reading palette tokens and Settings controls. `scripts/make-icon.swift` owns the icon geometry. The Xcode project, scheme, target, app product, source directory, and app entry point use Margin; the Swift package and test module use MarginCore. The bundle ID, OAuth callback, Keychain identifiers, and storage paths retain their existing values so installed credentials and saved data remain reachable.

Before release, inspect the icon at home-screen size and check headings, links, code, tables, quotes, and paired reading in every palette with Dynamic Type and VoiceOver.
